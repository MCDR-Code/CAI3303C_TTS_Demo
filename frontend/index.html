Using this from a phone

Run the API on your laptop (python imv_api.py), find your laptop's LAN IP (Windows: ipconfig → IPv4 Address), make sure your phone is on the same Wi-Fi, and enter http://<that IP>:5000 above. On iOS Safari / Android Chrome you can add this page to your home screen for a near-native launcher icon.
